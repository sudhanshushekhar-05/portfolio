A modern, highly interactive, and responsive personal portfolio website showcasing full-stack web development projects, AI/ML engineering, IoT hardware projects, skills, and background.

---

## 🎨 Overview & Features

- **⚡ Sleek & Modern Dark Design:** Engineered with rich CSS gradients, glassmorphism, smooth micro-animations, and dynamic visual effects.
- **📱 Fully Responsive:** Seamless layout transition across Mobile, Tablet, Laptop, and 4K Screens with a dynamic floating navigation pill bar and mobile drawer overlay.
- **💻 Interactive Work Showcase:** Dynamic project filtering cards with rich detail modal previews for deep-dive descriptions, tech tags, and live code links.
- **🛠️ Filterable Skills Matrix:** Categorized interactive skill cards covering Web Technologies, Programming Languages, AI & Machine Learning, and Developer Tools.
- **📍 Location & Contact Section:** Interactive contact form validation with dynamic feedback messages and embedded map integration.
- **✨ Smooth Scroll & Micro-Interactions:** Progress scroll bar indicator, custom cursor trails, interactive tilt cards, and glowing badges.

## 💻 Getting Started Locally

To run this repository on your local machine:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/sudhanshushekhar-05/portfolio.git
   ```

2. **Navigate to the Project Folder:**
   ```bash
   cd portfolio
   ```

3. **Launch the Application:**
   - Double-click `index.html` to view it in any modern web browser, or
   - Use VS Code **Live Server** extension for real-time live reloading.
